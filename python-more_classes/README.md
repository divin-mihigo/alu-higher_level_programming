# python-more_classes

This directory contains Python scripts that go deeper into classes and
objects: properties, class attributes, special methods (`__str__`,
`__repr__`, `__del__`), static methods and class methods.

## Files

| File | Description |
| ---- | ----------- |
| `0-rectangle.py` | Empty class `Rectangle` |
| `1-rectangle.py` | `Rectangle` with validated private `width` and `height` |
| `2-rectangle.py` | Adds `area` and `perimeter` methods |
| `3-rectangle.py` | Adds `__str__` to print the rectangle with `#` |
| `4-rectangle.py` | Adds `__repr__` so `eval()` can recreate an instance |
| `5-rectangle.py` | Prints `Bye rectangle...` when an instance is deleted |
| `6-rectangle.py` | Adds the `number_of_instances` class attribute |
| `7-rectangle.py` | Adds the `print_symbol` class attribute |
| `8-rectangle.py` | Adds the static method `bigger_or_equal` |
| `9-rectangle.py` | Adds the class method `square` |

## Requirements

- Python 3 (interpreter `/usr/bin/python3`)
- Files start with `#!/usr/bin/python3` and are executable
- No modules are imported
- Modules, classes and methods are documented
- Code follows the PEP8 style (`pycodestyle`)
