# python-classes

This directory contains Python scripts that introduce classes and objects:
defining a class, private attributes, validation, properties (getters and
setters), and instance methods.

## Files

| File | Description |
| ---- | ----------- |
| `0-square.py` | Empty class `Square` |
| `1-square.py` | `Square` with a private `size` attribute |
| `2-square.py` | `Square` with `size` type and value validation |
| `3-square.py` | `Square` with an `area` method |
| `4-square.py` | `Square` with a `size` getter and setter |
| `5-square.py` | `Square` with a `my_print` method printing with `#` |
| `6-square.py` | `Square` with a `position` attribute used when printing |

## Requirements

- Python 3 (interpreter `/usr/bin/python3`)
- Files start with `#!/usr/bin/python3` and are executable
- No modules are imported (except `__import__` in the test mains)
- Modules, classes and methods are documented
- Code follows the PEP8 style (`pycodestyle`)
