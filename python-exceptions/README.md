# python-exceptions

This directory contains Python scripts that practice error handling with
`try` / `except` / `finally` and with raising exceptions.

## Files

| File | Description |
| ---- | ----------- |
| `0-safe_print_list.py` | Prints x elements of a list and returns the number printed |
| `1-safe_print_integer.py` | Prints an integer with `"{:d}".format()` and returns True, or False if it is not an integer |
| `2-safe_print_list_integers.py` | Prints only the integers among the first x elements of a list |
| `3-safe_print_division.py` | Divides 2 integers and prints the result in the `finally` section |
| `4-list_division.py` | Divides 2 lists element by element, handling errors |
| `5-raise_exception.py` | Raises a type exception |
| `6-raise_exception_msg.py` | Raises a name exception with a message |

## Requirements

- Python 3 (interpreter `/usr/bin/python3`)
- Files start with `#!/usr/bin/python3` and are executable
- No modules are imported
- Code follows the PEP8 style (`pycodestyle`)
