# python-everything_is_object

This directory contains answers and scripts about the idea that everything
is an object in Python: identity vs equality (`is` vs `==`), `id()` and
`type()`, mutable and immutable objects, and how arguments are passed to
functions.

## Files

| File | Description |
| ---- | ----------- |
| `0-answer.txt` to `18-answer.txt` | Answers about types, identities, strings, lists and functions |
| `19-copy_list.py` | Function that returns a copy of a list |
| `20-answer.txt` to `28-answer.txt` | Answers about tuples and object identities |

## Requirements

- Python 3 (interpreter `/usr/bin/python3`)
- `19-copy_list.py` starts with `#!/usr/bin/python3` and is at most 3 lines
- No modules are imported
- Code follows the PEP8 style (`pycodestyle`)
