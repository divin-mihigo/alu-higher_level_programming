# Python - import & modules

This project covers importing modules, command-line arguments and
guarding code so it does not run when imported.

## Files

| File | Description |
|------|-------------|
| 0-add.py | Imports add from add_0.py and prints 1 + 2 = 3 |
| 1-calculation.py | Imports add, sub, mul, div from calculator_1.py |
| 2-args.py | Prints the number and list of arguments |
| 3-infinite_add.py | Prints the sum of all arguments |
| 4-hidden_discovery.py | Prints the names defined in hidden_4.pyc |
| 5-variable_load.py | Imports and prints a from variable_load_5.py |

## Requirements

- Ubuntu, Python 3 (task 4 needs Python 3.8.x)
- Code follows PEP 8 (pycodestyle)
- All files are executable
